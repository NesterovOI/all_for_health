# Ромашка лікарська (Matricaria chamomilla)

Ромашка є однією з найпопулярніших лікарських рослин у світі завдяки своїм протизапальним та заспокійливим властивостям.

## Користь для організму
* **Заспокоєння нервової системи:** Чай з ромашки допомагає долати безсоння та стрес.
* **Травлення:** Знімає спазми шлунка та зменшує запальні процеси ТРК.
* **Антисептичний ефект:** Використовується для полоскання горла при застудах.

## Рецепт приготування відвару
1. Візьміть **1-2 чайні ложки** сухих квіток ромашки.
2. Залийте **200 мл** окропу.
3. Настоюйте під кришкою протягом **10-15 хвилин**.
4. Процідіть та пийте теплим перед сном.

> **Важливо:** Не рекомендується вживати при індивідуальній алергії на айстрові рослини.
