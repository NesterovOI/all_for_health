
# Ромашка лікарська (Matricaria chamomilla)

Ромашка є однією з найпопулярніших лікарських рослин.

## Користь для організму

- **Заспокоєння нервової системи:** чай з ромашки допомагає розслабитися.
- **Травлення:** може допомагати при легкому дискомфорті.
- **Антисептичний ефект:** традиційно використовується для полоскання горла.

## Рецепт приготування відвару

1. Візьміть **1-2 чайні ложки** сухих квіток ромашки.
2. Залийте **200 мл** окропу.
3. Настоюйте під кришкою протягом **10-15 хвилин**.
4. Процідіть.

> **Важливо:** Не рекомендується вживати при індивідуальній алергії на ромашку.
